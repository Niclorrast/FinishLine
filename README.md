# proyecto-pintura-web
Proyecto final de mi grado superior en desarrollo de aplicaciones web.
Este proyecto se concibe con el objetivo de optimizar la gestión operativa
y la distribución de la carga de trabajo en un entorno profesional de servicios
de pintura. Ante el volumen de demanda actual, se hace necesaria una
herramienta que no solo actúe como escaparate corporativo, sino que facilite
la organización del equipo humano en función de las necesidades específicas
del cliente.
En la plataforma se integra una capa de gestión de datos dinámica mediante
una interfaz intuitiva. A través de ella, se permite a los usuarios conocer la
trayectoria del taller, consultar una galería de trabajos previos y solicitar
presupuestos personalizados; asimismo, se ofrece la posibilidad de adjuntar
imágenes para aumentar la precisión de la valoración técnica.
En el Backend, se centralizan todas las solicitudes en una base de datos
MySQL. Esto permite a la empresa gestionar incidencias, administrar citas
de manera eficiente y mejorar drásticamente los tiempos de respuesta y la
comunicación interna, con lo que se transforma la presencia digital en un
activo estratégico para la productividad del taller.
